# informed-decision

在真正需要你拍板的地方，把**机器视角的客观变化**翻译成**你视角的后果与取舍**，让你无需补课就能选。

它不产出决定，产出一份**决策简报**（影响驱动的 SCQA）：基线锚定、影响三问（多痛 / 多急 / 多广）、核心取舍、带代价的选项与推荐，证据细节折叠。

## 何时用

- 你说：**拿不准 / 该选哪个 / 你定 / 这样有风险吗 / 我不懂这块 / 要不要动 X**。
- agent 在高影响岔路口主动用：定核心接口、选存储或依赖、动数据、花钱、对外承诺。
- agent 主动发现异常或风险、需要你拍板时（异常推送）。
- 不来的情形：已授权、影响小且容易撤回的选择，agent 自己判断直接做；能自己查清的（读代码、看 git 历史、查文档），先查再问。

## 核心原则

1. **先分流。** 只有「非得你来定」的事才值得占你的注意力；判据是不可逆性、锁定时间、影响面、以及多个选项是否都说得通。
2. **先给参照系。** 你对孤立数字没有判断力——延迟 1.5 秒严不严重，取决于基线是 200ms 还是 2s。先一句「正常是什么样」。
3. **翻译，不陈述。** 不讲技术原理，把变化翻成三问：**有多痛**（直接损失）、**有多急**（距不可挽回的临界点）、**有多广**（波及下游 / 大客户 / 合规）。
4. **收敛成取舍，不抛开放问题。** 「你觉得怎么办」会让人卡住；「保交付还是省成本」只需要你判断优先级与资源。
5. **选项带代价，必须给推荐。** 通常 2 个有实质差异的方案，每个诚实写明收益与代价；标明推荐与把握度（高 / 中 / 低）——把握度不是成功概率。
6. **默认项不是授权。** 默认项默认等于推荐，不等于时说明理由；需要明确同意的操作会等你确认，不因沉默就执行。
7. **细节折叠。** 日志、报错、公式收进「详情」或明说「需要就贴」；你信任就快速拍板，存疑再展开核对。
8. **不替你做不可逆决定。** 删数据、动生产、对外承诺、花钱——再确定也要你点头。

避免的问题的完整清单见 `SKILL.md` 的「避免的问题」。

## 拍板之后

按你选定的走，不再安利另一个选项。你选了与建议不同的方案：只要风险和授权边界清楚，直接执行，不追问理由；仍有关键风险或授权不明，才回来找你确认。值得日后查阅的决策进 `./tmp/docs/memory/`（细则以 project-memory 为准），小决定不建档。

## 与其他 skill 的关系

- **calm-explain** —— 讲解风格、术语、切块、篇幅跟随难度、证据三档标签的唯一来源。本 skill 只引用，不复述。分工：calm-explain 讲「发生了什么」，本 skill 讲「往哪走」。
- **project-memory** —— 决策记录的存放与生命周期：何时记、记哪、`tags`、`STATE.md` 挂链；长简报需要留档也按它的约定落盘。
- **geeklens** —— 取舍取决于某段源码的行为时，先读源码；简报较长且证据主要来自代码时，用它出阅读版供你核对。

## 安装

把本目录复制或软链到你的 skills 目录，目录名须与 frontmatter 的 `name:`（`informed-decision`）一致：

```powershell
# OpenCode
Copy-Item -Recurse . "$env:USERPROFILE\.config\opencode\skills\informed-decision"

# Claude
Copy-Item -Recurse . "$env:USERPROFILE\.claude\skills\informed-decision"
```

或用 Skills CLI 只装这一个（`skillcrate` 仓）：

```bash
npx skills add wurenrumian/skillcrate --skill informed-decision --global --yes
```
